# gifer

TUI application for converting videos to GIFs.

<img width="740" height="798" alt="image" src="https://github.com/user-attachments/assets/99ba4be3-4325-4b0d-9804-0b231c14a66f" />

## Install

```bash
brew install vlwkaos/tap/gifer
```

## Usage

1. Run `gifer`
2. Copy a video file to clipboard (Cmd+C in Finder)
3. Paste in app to load video
4. Adjust settings (dimensions, fps, quality, loop)
5. Convert and copy output path

## Requirements

- macOS (Apple Silicon)
- FFmpeg (bundled via ffmpeg-sidecar)
